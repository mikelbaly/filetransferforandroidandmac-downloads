# File Transfer for Android & Mac

The official downloads repository for the Mac app by Mikel Besga.

[Download for Mac](https://github.com/mikelbaly/filetransferforandroidandmac-downloads/releases/latest/download/File-Transfer-for-Android-and-Mac.zip) · [Website and setup](https://filetransferforandroidandmac.pages.dev/) · [Installation instructions](https://filetransferforandroidandmac.pages.dev/download/)

Requires macOS 13 or later. One universal download supports Apple silicon and Intel. Release apps are signed by Mikel Besga with Developer ID, notarized by Apple, and include a stapled notarization ticket.

## Install

1. Download the ZIP and double-click it in Downloads.
2. Drag **File Transfer for Android & Mac** into Applications.
3. Open the app from Applications, choose a Mac folder and connect your phone. USB uses Android USB debugging; Wi-Fi uses Wireless debugging on Android 11 or later. The website explains both setups.

To update, quit the app and replace it in Applications with the latest downloaded copy.

## Free features and Pro

USB and Wi-Fi file transfers, copying, moving, deleting, folders, favourites, previews, themes and menu bar access are free. Optional Pro tools add backups, photo imports and file organisation. Pro purchases and restoration require the Mac App Store edition; they are not supported in this direct-download edition.

## Open-source helper

Each release includes the matching **ADB-Source.zip**, **Android-NOTICE.txt** and **ADB-Provenance.json**. The app bundles these too, and its Privacy & licences window can export the helper source/rebuild kit without Pro. The kit contains source archives, build scripts, patches and licence texts for rebuilding and relinking the helper. Each component retains its own licence and the rights those licences grant. This downloads repository does not license the application source or branding as open source.

`SHA256SUMS.txt` records checksums for the release assets.
